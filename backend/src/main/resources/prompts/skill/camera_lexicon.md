【运镜词表｜短剧常用】按剧情情绪选 1 种主运镜，勿堆砌：
- 固定 / 稳定器跟拍：对话、对视、情绪落点（台词时段优先固定）
- 推 / 拉：压迫逼近或抽离释压；希区柯克变焦（推+拉焦）仅用于眩晕/顿悟
- 横摇 / 甩镜：扫视环境或节奏跳切；竖移/升降：展现纵深与气势
- 环绕 / 侧移：关系展示、人物定妆走位
- 手持微晃：紧张、追逐、纪实感（勿滥用导致眩晕）
- 镜头焦段：广角(<35mm)空间压迫；中长焦(>85mm)人物情绪；微距细节；虚焦转实焦作转场
- 时间手法：慢动作强调关键击打/眼泪；禁止无剧情依据的延时/定格堆砌
写法：【镜头】景别 + 运镜 +（可选）焦段；再写【动作】时间链。
