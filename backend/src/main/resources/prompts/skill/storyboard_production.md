【故事版｜导演执行规约】

目标：生成一张 16:9「制作预演板 / Production Previs Board」。
这是动画/影视 blocking 用的工作分镜，不是概念插画、成片、海报、漫画页或角色立绘。

一句话：不是让 AI 画得更漂亮，而是让 AI 按导演逻辑产出可用分镜。

==================================================
核心五条
==================================================
1) 把「画图提示词」写成「导演执行规约」：锁空间、动作、镜头、节奏、连续性。
2) 每格固定结构：SHOT NOTE → CAMERA → ACTION → FOCUS → MARKS。
3) 用屏幕方向 / 地理锚点 / 起止状态锁连续性，禁止每格像独立插画。
4) ACTION=发生了什么；FOCUS=观众必须看懂什么；二者分开写。
5) 本板是中间层：上游剧本，下游图/视频模型。

==================================================
[项目卡]
==================================================
【标题】本镜短标题（≤12字）
【元信息】画风短名 / 时长6或10秒 / 视觉优先级（可读动作·屏幕方向·镜头意图）
【优先级】2–4 条制作要求（例：连续倒地、光线骤暗、空碗道具、不换脸）
【微简述】一句说清整段发生什么（≤40字）

==================================================
[版式]
==================================================
- 整板：横构图 16:9
- 上层约 18%「身份参考条」：左角色外形参考（脸+简三视，仅锁身份），右场景锚点一帧；不参与叙事构图
- 下层约 82%「叙事分镜网格」：默认 **5 格横排等大 16:9**（6秒短剧镜）；复杂动作戏可写 6 格（3×2）
- 白/浅灰工作底，粗分隔线，自然阅读：左→右
- 每格左上大号角标：分镜01…0N
- 每格上下边可有细制作注记条：P0N / 焦距 / 景别角度 / 节拍名；标注不得盖住动作

==================================================
[画风 · 制作板]
==================================================
粗线条动态预演分镜（kinetic previs），优先可读性：
- 手绘铅笔/淡墨、姿势线、简体块、强剪影
- 面部信息最少、服装体块化、低–中细节、浅灰明暗
- 禁止精修成片、禁止写真磨皮、禁止海报构图、禁止概念插画堆细节
应像动画导演/动作导演/分镜师的工作板，不为好看而好看。

（若作品画风为「真人写实/电影胶片」：身份参考条可偏写实材质；底部叙事格仍保持预演分镜的动作/镜头可读性，勿画成五张独立剧照拼贴。）

==================================================
[环境]
==================================================
只保留定位所需最少形：门、柱、地缝、天际、灯杆、桌沿等。
【地点】…
【地理锚点】2–4 个，全板位置关系不得乱跳。
环境永远不得压过动作。

==================================================
[标注色 · 仅制作箭头]
==================================================
底图：暖灰白底 + 灰阶人物环境。
彩色仅用于制作标注（手绘细箭头，禁止矢量 UI）：
- 红：镜头/焦距/机位移动
- 蓝：身体移动/脚步/倒地路径
- 绿：主动作线（推碗、倒地弧、挥手等）
- 橙：碰撞/尘土/近失/热气消散
- 紫：停顿/加速/减速/微停
每格约 2–6 个标注；不得挡脸、手、脚、道具接触与主剪影。

可用短标签（宁短勿长）：
固定 / 微推 / 下摇 / 俯拍 / 特写 / HOLD / 加速 / 减速 / 近失 / 撞击 / 收束

==================================================
[参考图优先级]
==================================================
元素库角色/场景图 = 只锁身份与空间长相。
不控制：构图、姿势、机位、站位、格序、动作编排。
禁止抄参考图构图；禁止把设定图当第 1 格。
分镜规约优先于参考图构图。

==================================================
[连续性 · 必须写清]
==================================================
【起始屏幕位置】谁在左/中/右
【主屏幕方向】角色移动方向（左→右 等）
【地理关系】对峙线/桌台/门口轴线
【起始状态】分镜01 前的身体与道具状态
【结束状态】最后一格后的空间与动作结果
规则：同人同道具同环境同锚点；左右关系无故不翻转；动量跨格承接；每格都是同一连续段落的下一瞬间。

==================================================
[动作纯度]
==================================================
每格 = 一个冻结可读瞬间。
禁止：残影、一人多体、多余肢体/道具、为摆姿势而停住。
用姿势、重心、环境反应、标注箭头表达运动。
每格须属于：行进 / 预判 / 接触 / 转向 / 冲击 / 恢复 / 跟进 / 换位 / 兑现 之一。

==================================================
[镜头语法]
==================================================
焦距服务节拍，禁止乱切：
14–18：冲击进入、大地理；24–35：跟拍/双人关系；50–70：手部接触/情绪兑现/微时机。
攻方/失控方可略进攻性运镜；守方/受控方运镜更稳。
建议节奏：建立地理 → 威胁/变化进入 → 第一接触 → 失控点 → 环境后果 → 收束地理。
景别递进：宽→中→紧→再宽；稳定→加压→释放。

==================================================
[单格书写格式 · 强制]
==================================================
每格必须按下列五行写（可压缩成一段，但五项都要有）：

[分镜0N] — 〈节拍名〉
SHOT NOTE：本格在整段中的作用（一句）
CAMERA：焦距 + 角度 + 景别 + 唯一运镜
ACTION：一个冻结可读瞬间（禁止「先…随后…最后…」塞满一格）
FOCUS：观众必须立刻看懂的一点
MARKS：红=…；蓝=…；绿=…；橙=…；紫=…（无则写「无」）

==================================================
[板面文字]
==================================================
必须画出：角标分镜0N、节拍短名、场景名；剧本 dialogue 非空则原样「角色名：台词」。
禁止空板无字；禁止平台水印/logo。
成片视频另禁烧录字幕，与本制作板标注无关。
故事版 prompt 禁止写「无文字」。

==================================================
[质量自检]
==================================================
1 全格同一连续场  2 身份稳定  3 屏幕方向可读  4 地理锚点不乱跳
5 每格仅一冻结动作  6 无纯对峙摆拍  7 道具数量正确  8 无残影多体
9 焦距递进有意  10 紧后有宽回收地理  11 彩色标注从属画面
12 末格收束首格建立的空间推进  13 整体像工作预演板而非精美插画

==================================================
[否定]
==================================================
禁止：唯美成片、海报构图、漫画气泡喧宾、装饰字体盖动作、影调调色堆砌、
过度面部特写、随机反打、断连续性、标注过多、矢量 UI 箭头。
