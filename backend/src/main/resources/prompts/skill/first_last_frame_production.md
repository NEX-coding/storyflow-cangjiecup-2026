【首尾帧｜静帧生产规约】

对齐开源 FLF2V 惯例（LTX / Seedance / DirectorSKILL 等）：
静帧只描述「冻结瞬间」；视频提示词只描述「两帧之间的过渡」。

==================================================
核心分工
==================================================
1) first_frame / last_frame 的 prompt = 单帧剧照静帧（Image prompt）
2) videoPrompt = 首尾帧驱动的过渡（只写运镜 + 动作链 + 时长），禁止复述静帧清单
3) 两帧必须可插值：同一身份、同一服装、同一场景轴线；尾帧相对首帧只改姿态/光态/道具接触之一为主变

==================================================
静帧结构（每条 80–160 字，中文）
==================================================
【画面风格｜…】画风短名 + 材质关键词（禁止运镜/时长词）
【画幅】16:9 单帧电影静帧（不是角色设定板、不是三视图、不是多格故事版）
【景别·机位】景别 + 平视/略俯/略仰 + 可选焦段（例：中景·平视·约50mm）
【场景】地点 + 时间 + 主光向（两帧同一空间锚点）
【主体】(@名) 外形一句 + 此刻冻结姿态/表情/道具接触（一个瞬间，禁止「先…随后…」）
【构图】主体屏幕位置（左/中/右），前后景层次一句
【首尾配对】
  · 首帧：起幅冻结点（例：捧碗吞咽瞬间）
  · 尾帧：落幅冻结点（例：摔地瞬间）；须写「与首帧同一人同一服装同一场景」
【严禁】运镜、时长、推拉摇移、多格分镜、角色三视图拼贴、设定表白底、字幕水印、换脸换装年龄漂移

==================================================
videoPrompt 结构（首尾帧模式，建议 80–140 字）
==================================================
【风格参考】一行（可含运镜气质；全篇只出现一次）
【首尾帧驱动】以首帧为起点、尾帧为终点；只生成两帧之间连续动作
【一句话概述】≤40字
【过渡】从「起幅动作」到「落幅动作」的一条物理路径（可「先…随后…最后…」）
【镜头】景别 + 唯一运镜（从运镜词表选 1 种）
【声音】剧本有台词时必须原样「角色名：台词」（多人用 / 分隔；画外音保留）；成片无烧录字幕
【一致】同一人设服装场景；不换脸；成片无烧录字幕
【节奏】时长：6或10秒

模板参考（开源 FLF 常见写法）：
「[运镜] as [主体] [连接两帧的过渡动作]。[可选环境声]」
勿把首帧/尾帧画面内容再抄一遍；勿删除剧本台词。

==================================================
质量自检
==================================================
1 静帧无运镜/时长词  2 每帧仅一冻结瞬间  3 两帧同人同服同场景
4 尾帧相对首帧主变清晰且物理可连  5 非设定板/三视图  6 video 只写过渡
