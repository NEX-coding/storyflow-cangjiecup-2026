# StoryFlow 开发指南

> 最后更新：2026-10-23

## 1. 环境要求

| 组件 | 版本 / 说明 |
|---|---|
| Java | **21**（Spring Boot 3.4） |
| Node.js | 18+ |
| pnpm | 前端包管理 |
| Ollama | 本地 LLM，模型 `qwen3.5:4b` |
| 邮件 SMTP | 注册验证码（163 等，见下文） |

## 2. 一键启动顺序

```bash
# 1. Ollama
ollama pull qwen3.5:4b
ollama serve

# 2. 后端（需 Java 21）
export JAVA_HOME=/opt/homebrew/Cellar/openjdk@21/21.0.12.1/libexec/openjdk.jdk/Contents/Home
cd backend && mvn spring-boot:run

# 3. 用户端
cd frontend && pnpm install && pnpm dev # :5173

# 4. 管理端（可选）
cd admin && pnpm install && pnpm dev # :5174
```

## 3. 配置文件

### 3.1 Spring Profiles

默认激活：`dev,local`（见 `application.yml`）

| Profile | 用途 |
|---|---|
| `dev` | H2 文件库 `./data/storyflow`，H2 Console 开启 |
| `local` | 本地 SMTP（**已 gitignore**，勿提交密钥） |
| `prod` | MySQL |

### 3.2 邮件（注册验证码）

复制模板并填写：

```bash
cp backend/.env.example backend/.env
# 或编辑 backend/src/main/resources/application-local.yml（已在 .gitignore）
```

| 变量 | 说明 |
|---|---|
| `SMTP_HOST` | 默认 `smtp.163.com` |
| `SMTP_PORT` | 默认 `465` |
| `SMTP_USER` | 发信邮箱 |
| `SMTP_PASS` | **授权码**（非登录密码） |
| `SMTP_FROM` | 发件人显示地址 |

验证码：6 位数字，**10 分钟**有效，**60 秒**内不可重复发送。

### 3.3 Ollama

`application.yml` → `storyflow.ollama`：

- `base-url`: http://localhost:11434
- `model`: qwen3.5:4b
- `num-ctx`: 8192

管理端「AI 设置」可在线修改并测连通性。

## 4. 数据库

- **开发**：H2 文件 `backend/data/storyflow.mv.db`
- **Console**：http://localhost:8080/h2-console 
 JDBC URL：`jdbc:h2:file:./data/storyflow`
- **生产**：MySQL `storyflow` 库（profile `prod`）

JPA `ddl-auto: update`，实体变更会自动建表/加列。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 后端启动失败「请先登录」 | 已修复：启动任务不再依赖登录用户；若仍出现，检查 `DataInitializer` |
| 注册收不到验证码 | 检查 SMTP 配置；看后端日志 `Register code mailed` |
| AI 生成很慢/失败 | 确认 Ollama 在跑、`qwen3.5:4b` 已 pull |
| 改了 `prompts/system/*.md` 不生效 | 重启后端（`DataInitializer` 会 `syncFromClasspath` 写入 DB）；管理端改 DB 也可临时覆盖 |
| 提取资产变慢 | 正常：角色/场景/道具分三次 LLM，再为每条资产生成 imagePrompt |
| H2 数据库被锁 | 停掉占用 8080 的后端进程后再启动 |
| 分镜提示词仍是英文 | 默认已是中文；若旧数据是英文，点「重新生成」即可；要英文需在助手里说「用英文」 |
