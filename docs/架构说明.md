## 1. 总体架构

```
┌─────────────┐   ┌─────────────┐
│ frontend    │   │ admin       │
│ :5173       │   │ :5174       │
└──────┬──────┘   └──────┬──────┘
       │ REST / SSE      │ REST
       └─────────┬───────┘
                 ▼
       ┌─────────────────┐
       │ Spring Boot     │
       │ :8080 /api      │
       ├─────────────────┤
       │ AuthInterceptor │──► CurrentUserService（ThreadLocal 用户）
```

## 2. 后端模块（单模块 Maven 项目）

| 包路径 | 职责 |
|---|---|
| `controller/` | REST 入口：项目、工作台、认证、管理、反馈 |
| `assistant/` | AI 助手：流式对话、意图解析、执行剧本/资产/分镜/原文修改 |
| `service/` | 业务：`WorkspaceService`、`AuthService`、`ProjectService` 等 |
| `ai/` | `LlmGateway`、`OllamaClient`：模板读取、JSON 生成、流式分镜 |
| `entity/` + `repository/` | JPA 实体与仓储 |
| `config/` | 安全、拦截器、种子数据、Ollama 配置 |

## 3. 前端模块

| 路径 | 职责 |
|---|---|
| `frontend/src/pages/` | 项目列表、工作台、设置、历史、反馈 |
| `frontend/src/modules/assistant/` | 右侧 AI 助手（SSE 流式、状态同步） |
| `frontend/src/components/workspace/` | 分镜行、资产面板、原文/剧本列 |
| `frontend/src/auth/` | 登录态、Token 持久化 |
| `admin/` | Prompt 模板、Ollama 配置、仪表盘 |

## 4. 核心数据流

### 4.1 创作流水线

```
原文 → script/generate → 剧本条目
 → assets/extract → 人物/场景/道具 + imagePrompt
 → shots/generate → 分镜 + videoPrompt + referencePrompts
 → export → JSON / Markdown 提示词包
```

### 4.2 AI 助手

```
用户消息 → AssistantService
 → 意图分类（LLM + 关键词兜底）
 → 执行：改原文 / 生成剧本 / 提取资产 / 重生分镜 / 删分镜 …
 → SSE 推送 status / token / shots / done
```

分镜重生时携带 **语言偏好**（中文/英文）传入 `LlmGateway.streamGenerateShot`。

## 5. 持久化实体（主要）

| 表/实体 | 说明 |
|---|---|
| `users` | 用户账号 |
| `auth_sessions` | 登录 Token（30 天） |
| `email_verification_codes` | 注册验证码 |
| `projects` | 项目（按 userId 隔离） |
| `source_texts` | 小说原文 |
| `script_entries` | 结构化剧本 |
| `assets` | 资产库 |
| `shots` + `reference_prompts` | 分镜与参考图提示词 |
| `assistant_messages` | 助手聊天记录 |
| `project_snapshots` | 版本快照 |
| `prompt_templates` | 可编辑 Prompt 模板（由 `resources/prompts/**/*.md` 启动同步） |

## 5.1 提示词工程

长中文提示词不进 Java，统一放在：

```
backend/src/main/resources/prompts/
  system/   → script_generate / asset_extract / shot_generate / assistant
  style/    → style.{画风名}（总览 + 风格包子目录）
  skill/    → skill.camera_lexicon / skill.asset_image_guide
```

`PromptCatalog`：DB active 优先 → classpath → 极简兜底。业务只负责编排与变量注入。
| `ai_usage_logs` | 生成历史 |

## 6. 鉴权

- `AuthInterceptor`：解析 Bearer Token → 设置 `CurrentUserService`
- 未登录访问需用户数据的 API → `BusinessException(401, "请先登录")`
- `/api/auth/*` 注册/登录无需 Token
