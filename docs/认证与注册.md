# 认证与注册

> 最后更新：2026-10-04

## 1. 概述

- **注册**：邮箱 + 6 位验证码 + 密码（≥6 位）
- **登录**：邮箱 + 密码
- **鉴权**：服务端 Session Token（非 JWT），30 天有效
- **隔离**：每个用户只能访问自己的项目与历史

> 已移除旧版 `local@storyflow.com` 默认账号；未登录无法使用工作台。

## 2. API

| Method | Path | 说明 |
|---|---|---|
| POST | `/api/auth/register/send-code` | 发送注册验证码 |
| POST | `/api/auth/register` | 注册并返回 Token |
| POST | `/api/auth/login` | 登录 |
| POST | `/api/auth/logout` | 登出（销毁 Token） |
| GET | `/api/auth/me` | 当前用户信息 |

### 2.1 发送验证码

```json
POST /api/auth/register/send-code
{ "email": "you@example.com" }
```

限制：
- 邮箱未注册
- 同一邮箱 60 秒内不可重复发送
- 验证码 10 分钟有效

### 2.2 注册

```json
POST /api/auth/register
{
 "email": "you@example.com",
 "code": "123456",
 "password": "your-password",
 "nickname": "可选昵称"
}
```

响应含 `token` 与 `user`（id、email、nickname、role）。

### 2.3 请求头

```
Authorization: Bearer <token>
```

或：

```
X-Auth-Token: <token>
```

## 3. 前端

- 侧栏「点击登录/账户」→ `LoginModal`
- Tab：**登录** / **注册**
- 注册：邮箱 → 发送验证码（60s 倒计时）→ 填码 + 密码 → 注册并登录
- Token 存 `localStorage`（见 `frontend/src/lib/auth.ts`）

## 4. 邮件配置

SMTP 与课表站相同（163 授权码）。配置方式见 [开发指南.md](./开发指南.md#32-邮件注册验证码)。

未配置 SMTP 时，发送验证码会返回「邮件服务未配置」。
